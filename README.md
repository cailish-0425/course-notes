# course-notes

从课堂录音转写、个人笔记等零散材料中，提炼出结构清晰、重点突出、兼顾理论与实践的高质量课程笔记。

> 适用于：学习复盘、面试准备、知识沉淀、二次整理

---

## 解决什么问题

课堂录音转写 + 个人笔记 → 高质量结构化笔记，这个过程中最常见的三个坑：

**坑一：删错了内容**
把老师顺手举的例子、真实工作场景、踩坑提醒当口头语删了。这些内容的价值远高于"标准知识点"。

**坑二：所有内容套同一个模板**
概念型内容需要"定义+本质+边界"，案例型内容需要"背景+问题+启发"，流程型内容需要"步骤+目的+易错点"。用同一种写法会让某些内容变得很难读。

**坑三：输出结构太死**
不是每节课都有"案例汇总"，不是每个知识点都需要"面试怎么问"。强制 8 个模块全输出会导致凑数内容。

这个框架用三个核心方法解决这些问题：
1. 一句话判断内容价值
2. 内容类型→表达形式映射
3. 必须模块+可选模块的灵活输出结构

## 安装使用

这是一个 [Claude Code](https://docs.anthropic.com/claude-code) Skill 文件。

### 全局安装（推荐）

```bash
mkdir -p ~/.claude/skills
cp SKILL.md ~/.claude/skills/course-notes.md
```

安装后重启 Claude Code，输入 `/course-notes` 即可使用。

### 项目级安装

```bash
mkdir -p <your-project>/.claude/skills
cp SKILL.md <your-project>/.claude/skills/course-notes.md
```

项目级安装后，进入该项目目录时 skill 自动可用。

### 不通过 Claude Code 使用

也可以直接参考 SKILL.md 的流程，手动或用其他 AI 工具执行笔记整理。

## 核心方法

### 内容价值判断

> 删掉这段内容，会不会损失理解课程所需的信息？

会 → 保留。不会 → 删除。

### 内容类型→表达形式

```
概念型 → 定义+本质+边界+区别
原理型 → 逻辑+因果+机制+设计原因
流程型 → 步骤+目的+关键动作+易错点
对比型 → 表格
案例型 → 案例卡片(背景+问题+解释+启发)
经验型 → 技巧卡片(内容+场景+用法+注意)
场景型 → 场景拆解(描述+挑战+应对+迁移)
```

### 工作流程

```
Step 1: 清洗（删噪声、修错误、术语标准化、补逻辑）
Step 2: 重构（定主线、分模块、选形式、提经验）
Step 3: 检查（自检清单，发现问题先修正再输出）
```
